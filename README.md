# 绍宋·中兴 — MUD 文字游戏

基于历史穿越小说《绍宋》（榴弹怕水 著）的单文件浏览器 MUD 原型。扮演穿越成宋高宗赵玖的现代人，重走建炎元年主线，改写靖康之后的历史。

## 运行

直接用浏览器打开 `绍宋中兴-MUD原型.html` 即可，无需服务器、无需构建、无外部依赖。

## 玩法

你是赵玖。明道宫三选一后车驾抵达下蔡，与金军隔淮相峙。每旬（10 天一旬）做一次决策，8 旬后下蔡决战。

### 核心循环

```
每旬决策（7 种备战 + 情报 + 朝堂 + 后宫 + 时局图）
  → 点"本旬结束"推进
  → 季节轮转（秋→冬→春），金军秋来春去
  → 8 旬后下蔡决战 → 四结局
```

### 系统一览

| 系统 | 说明 |
|---|---|
| 军事 | 练兵/犒军/办械/城防/招募民夫/编练骑兵 |
| 经济 | 国库收支、发国债、度田清丈、港运粮草 |
| 情报 | 探事司（杨沂中），情报影响事件 |
| 朝堂 | 政事堂议事、召对行在文武、三派角力（主战/主和/中间） |
| 后宫 | 3 位妃子 × 3 话题对话、留幸、选妃/浣衣/翻牌/酒池肉林 |
| 君德 | 0-100，高=贤能低=昏聩；昏君路线可强占梁红玉（韩世忠必反） |
| 时局图 | 140 座城池、6 势力（金/宋/西夏/大理/交趾/交战）、滚轮缩放拖拽 |
| 兵种 | 步兵/骑兵/弓兵；四种阵型（方阵/雁行/长蛇/钩镰）相克 |
| 野战 | 北伐流程：选目标 → 选阵型 → 按兵种地形结算 |
| 关隘 | 6 座天下关隘（潼关/大散关/仙人关/雁门关/居庸关/剑门关），守军 ×1.6 |
| 守将 | 8 位名将各有忠诚度（岳飞 98 / 宗泽 95 / 张俊 70），影响投降倾向 |
| 兵牌 | 张俊所部可在大地图上拖拽移动 |

### 关键数值

- 开局：国库 50 万贯、月入 12 万、月支 8 万；皇权威势 40、民心 55、君德 60
- 下蔡宋军 3 万（张俊统御 85），金军兀术 2.5 万，8 旬后到达
- 战力公式：`兵力 ×(0.5+训练/200) ×(0.5+士气/200) ×(0.5+装备/200) ×(1+(统御-70)/100) × 地形系数`
- 季节：turn 1-2 秋 / 3-5 冬（黄河结冰，金军战力 ×1.15）/ 6+ 春（兀术追击不退）

### 设计原则

- 历史题材克制处理，不写露骨描写
- 对话贴合《绍宋》原文语感
- 机制数值自洽
- 单文件自包含，原生 JS，无框架
